# Security policy

## Supported version

Only the latest commit on the default branch is maintained during the `v0.1`
proof-of-concept phase.

## Reporting a vulnerability

Do not publish exploit details, sensitive data, private keys, or seed phrases in
a public issue.

Use GitHub private vulnerability reporting for this repository when available.
If that channel is unavailable, contact the project owner through
[rugbuster.io](https://rugbuster.io/) with a short, non-sensitive request for a
private reporting channel.

Please include:

- affected commit or version;
- reproducible steps using non-sensitive test data;
- security impact;
- suggested remediation, if known.

## Scope reminder

This project is a read-only experimental scanner. It must never request wallet
secrets, hold keys, sign operations, or submit transactions. Reports are risk
signals, not audits or guarantees.
